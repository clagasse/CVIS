CVIS Climate Vulnerability Portal

Climate Vulnerability Indicators for Salmon

A data-informed, indicator-based framework integrating climate projections, habitat assessments, demographic status, and genetics data to evaluate the relative vulnerability of Pacific salmon Conservation Units (CUs) in the Fraser River Basin, British Columbia.

Draft - For Internal Review Only
This portal displays preliminary scientific outputs and data under active development. Results have not been fully peer-reviewed and should be interpreted with caution. Do not distribute without permission of the authors.
Supplement S1

Indicator Descriptions & Baseline Outputs

A detailed documentation of the CVIS framework, detailing the scientific rationale, mathematical formulations, data sources, and standardization functions for the 17 vulnerability indicators. The report includes basin-wide spatial projections and baseline indicator distribution plots across all evaluated Conservation Units.

Supplement S2

Conservation Unit Reports Dashboard

An interactive dashboard compiling individual profiles for Pacific salmon Conservation Units in the Fraser River Basin. Each profile contains spatial boundaries, demographic metrics, life-stage phenology, spawning and rearing habitat indicators, upstream migration conditions, marine exposure, and scoring sensitivity analyses.
